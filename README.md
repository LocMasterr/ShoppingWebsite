# GAY TECH STORE — Đồ án 1 Nhập môn Công nghệ Thông tin (CSC00004)

> **Slogan:** "Gaming gear khó, có Gay Tech lo!"

## 1. Giới thiệu
**Gay Tech Store** là website thương mại điện tử khởi nghiệp chuyên cung cấp thiết bị gaming, phụ kiện máy tính và giải trí dành cho sinh viên.

## 2. Cách chỉnh sửa nhanh dữ liệu (Chỉ cần mở 1 file duy nhất)
Mọi dữ liệu của website nằm tập trung tại file `js/products.js`:
- **Sửa/Thêm sản phẩm:** Chỉnh sửa mảng `PRODUCTS_DATA` trong `js/products.js`. Các nút lọc danh mục và số đếm tổng sản phẩm sẽ tự động cập nhật.
- **Sửa thông tin thành viên nhóm:** Chỉnh sửa mảng `TEAM_MEMBERS_DATA` trong `js/products.js`, trang `about.html` sẽ tự động hiển thị theo.

## 3. Cách chạy thử trên máy tính
1. Đảm bảo giữ nguyên thư mục `img/` chứa 7 file ảnh gốc (`logo.jpg`, `chuot.jpg`, `lotChuot.jpg`, `manHinh.jpg`, `phim.jpg`, `taiNghe.png`, `tayCam.png`).
2. Mở trực tiếp file `index.html` bằng trình duyệt web bất kỳ (Chrome, Edge, Safari, Firefox).
