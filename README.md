# GAY TECH STORE — Đồ án 1 Nhập môn Công nghệ Thông tin (CSC00004)

> **Slogan:** "Gaming gear khó, có Gay Tech lo!"

## 1. Giới thiệu dự án
**Gay Tech Store** là website thương mại điện tử khởi nghiệp chuyên cung cấp thiết bị gaming, phụ kiện máy tính và thiết bị giải trí hướng tới đối tượng khách hàng là sinh viên đại học.

## 2. Cấu trúc thư mục
- `index.html`: Trang chủ, danh mục sản phẩm, tìm kiếm, lọc, sắp xếp, modal chi tiết, giỏ hàng và thanh toán mô phỏng.
- `about.html`: Giới thiệu câu chuyện startup, mô hình kinh doanh, sứ mệnh, tầm nhìn, thành viên nhóm và minh bạch sử dụng AI.
- `contact.html`: Trang thông tin liên hệ và biểu mẫu gửi lời nhắn mô phỏng có kiểm tra dữ liệu.
- `css/style.css`: Giao diện Dark Gaming UI kết hợp hệ thống Responsive đa thiết bị.
- `js/products.js`: Dữ liệu 6 sản phẩm chính hãng kèm mức giá và đường dẫn ảnh nội bộ.
- `js/app.js`: Logic xử lý tìm kiếm, lọc, sắp xếp, giỏ hàng (`localStorage`), đặt hàng mô phỏng và thông báo Toast.
- `img/`: Chứa logo (`logo.jpg`) và 6 ảnh sản phẩm (`chuot.jpg`, `lotChuot.jpg`, `manHinh.jpg`, `phim.jpg`, `taiNghe.png`, `tayCam.png`).

## 3. Cách chạy thử trên máy cá nhân (Local)
1. Giải nén thư mục dự án.
2. Mở trực tiếp file `index.html` bằng trình duyệt (Chrome, Edge, Firefox, Safari) hoặc chạy qua tiện ích **Live Server** trên VS Code.
